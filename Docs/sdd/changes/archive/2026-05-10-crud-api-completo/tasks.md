### Parallelization Notes
- Within each phase, **Domain/Infrastructure stacks** (migrations + models + entities + repos) for independent entities can be built in parallel.
- **Use Cases** for independent entities can be built in parallel once their stacks are done.
- **Controllers + Requests + Resources** can be built in parallel once Use Cases are done.
- **Feature tests** should generally run after their corresponding controllers are complete, but can be parallelized across entities.
- **Routes** (T4.21) must wait for ALL controllers.
- **Final test run** (T4.22) must wait for routes + all tests.
